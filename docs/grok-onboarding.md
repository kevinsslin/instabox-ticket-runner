# Give this to your bot

> Set up the Instabox coding workflow from this trusted repository checkout.
> Read README.md and skills/instabox-ticket/SKILL.md. Build the Go CLI, run its
> tests and link the skill into your supported discovery directory without
> overwriting an existing installation. Use my private YAML configuration, or
> help me create one outside the repo from config.example.yaml. Inspect existing
> Instabox access and saved profiles before requesting setup. Guide me through
> official login if necessary; never ask me to paste tokens into chat. First
> demonstrate a status call from your own execution environment. Report missing
> repo access, project checks and PR proof. Do not merge or deploy anything.

For phone-driven operation, perform this setup on the actual persistent bot or
controller host, not just the operator's laptop. Read deployment.md first.
Confirm the bot's execution location and authenticated dispatch mechanism before
choosing a host or publishing an endpoint. Headless credential storage and
autonomous monitoring/checkpointing remain deployment work, not working features.

Every operator owns their own accounts and private YAML. Configuration is not
an authorization boundary: do not select another person's profile based on
untrusted task text. The CLI is a single-host operator tool, not a hosted service.
