# Sharing this workflow

Distribute one generic repo containing the Go CLI, skill and generic YAML example.
Each person uses their own controller, accounts and private config. Never include
company-specific setup, actual workspace IDs, tokens, task state or login snapshots.

Before presenting a complete workflow, verify fresh official login, real private
repo access, one ticket/branch/PR, review edits on the same VM, interrupted-controller
recovery and a second user's independent onboarding. Record actual cost and timing.
Clean-clone installation on the author's computer is not second-user proof.

Current limits: single trusted host, serialized Codex profiles, native OS credential
store, dependency on Instabox CLI. Long-term refresh, automated PR publishing,
cancellation and safe deletion are still pending. Read VALIDATION.md before claims.

For a short demo show the requested task, bot command, VM, tests/diff, PR and review
revision. Hide credentials, private code and issue contents. Link a tested release
when one exists; distinguish current observations from planned behavior. Disclose
applicable sponsorship or referral relationships.
